# 蛋白组学分析插件 · 使用说明（给生物学家）

> 你不需要安装任何软件、不需要会 R、不需要会 Docker。
> 所有分析在 DeepSeek Harness 里用**中文对话**完成，分析过程自动、逐步可查。

## 你需要准备什么

1. **蛋白表达矩阵**（`origin_data.txt`，Tab 分隔），格式：

   ```
   Accession    GeneName   Description      NC_1     NC_2     HC_1  ...
   P12345       Alb        血清白蛋白      1234.5   1456.2   876.3
   ```
   - 前 3 列：蛋白编号（UniProt Accession）、基因名、描述
   - 后面的列：每个样本一列，值为丰度数字，缺失写 `NaN`
   - 通常直接来自 MaxQuant / Proteome Discoverer 等软件的定量结果

2. **样本分组表**（可选，`sample_info.txt`）：
   ```
   Sample   Group   Batch(可选)
   NC_1     NC      1
   HC_1     HC      1
   ```
   - 没有也可以：插件会从样本名自动推断分组，但请在分析前确认它推断得对不对
   - `Batch` 列：如果样品是**分批**制备/上机的，填上批次号，插件可以自动校正批次效应

3. 把你的数据文件放进电脑里的一个文件夹（比如 `D:\我的实验\`），然后把文件夹路径告诉它。

## 怎么用

直接在对话框说，例如：

> 我的蛋白组数据在 `D:\我的实验\origin_data.txt`，样本分组在 `D:\我的实验\sample_info.txt`，
> 小鼠样本，帮我分析 HC、HD 分别对 NC 的差异蛋白。

接下来它会：
1. **自动检查环境**（第一次会自动安装 R 和相关软件包，约 10–20 分钟，之后永远不用管）；
2. **自动质检数据**，并把推断出的分组、缺失情况报告给你，**和你确认比较组**；
3. 按步骤执行：**归一化 → PCA → （批次校正）→ 差异分析 → GO/KEGG 富集 → GSEA**，每一步在对话里都能看到摘要；
4. 最后给你一份**解读报告**：哪些蛋白上调/下调、富集了哪些通路、建议重点关注哪些候选靶点。

## 结果在哪

每一步的结果都在项目文件夹的 `res/` 里：

```
res/norm_results/      归一化报告、小提琴图
res/pca_results/       PCA 图（样本聚类情况）
res/dea_results/<比较组>/   差异结果 CSV、火山图
                        ├─ enrichment_results/   GO/KEGG 富集表和图
                        └─ gsea_results/         GSEA 结果
```

- **CSV** 可以用 Excel 打开
- **PDF** 图可以直接放进论文
- 想重跑某一步：直接说“用更严格的阈值（p<0.01）重新做差异分析”，它会只重做受影响的步骤

## 常见问题

| 现象 | 含义 / 处理 |
|---|---|
| “首次安装软件包需要 10–20 分钟” | 正常，只需一次，之后秒开 |
| 提示批次列缺失 | 样品若分批次制备，建议在分组表加 `Batch` 列再重跑，结果更可靠 |
| 某比较组没有显著蛋白 | 阈值可能过严，可以让它放宽阈值或改用自动阈值 |
| 想换物种（人/大鼠） | 第一次用该物种时需联网构建注释背景库（一次，之后缓存） |

## 给管理员的离线部署

实验室无外网时：在有网机器上执行
`scripts/create-offline-snapshot.ps1` 生成快照，实验室机器上用
`proteomics_environment action=restore_snapshot snapshotPath=<zip>` 恢复，全程零网络。
